# Screen: Unlocks (garage)

HCR2-style mini garage — not binary unlock chips.

## Behavior

- Enter from Title or Fail.
- Big cart centered; bank shown.
- Six levelable bars (max **5** each). Tap to buy next level with bank.
- Back to Title (then Play).
- No mid-run access.

## Bars

1. Chassis — wider safe lean  
2. Mag-locks — cargo sticks harder  
3. Rail sync — softer knocks  
4. Gyro dampers — faster return to center  
5. Station magnet — wider deliver gate  
6. Payday — more score per station
