# Screen: Options

## Behavior

- **Music** mute toggle
- **SFX** mute toggle
- Short **controls** blurb (←/→, A/D, L/R pads; at stations L/R fling for bonus)
- Back to Title
- No remapping

|   In station strip: L/R = fling only     |
