# Screen: Options

## Behavior

- **Music** mute toggle
- **SFX** mute toggle
- Short **controls** blurb (←/→, A/D, L/R pads, fling on stations)
- Back to Title
- No remapping

## Lo-fi

```
+------------------------------------------+
|              OPTIONS                     |
|                                          |
|   Music          [ ON / OFF ]            |
|   SFX            [ ON / OFF ]            |
|                                          |
|   Controls:                              |
|   L/R bump = arrows or A/D or pads       |
|   Fling = space or center button         |
|   at stations for bonus                  |
|                                          |
|              [ BACK ]                    |
+------------------------------------------+
```
